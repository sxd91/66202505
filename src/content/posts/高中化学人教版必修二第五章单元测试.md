# 高中化学人教版必修二第五章单元测试

## 一、单选题

1. 中国古代诗词和书籍中蕴含着化学知识。下列说法错误的是（  ）
A. “白玉金边素瓷胎，雕龙描凤巧安排”，陶瓷材料是人类应用最早的硅酸盐材料
B. 我国古代典籍中有“石胆……浅碧色，烧之变白色者真”的记载，其中石胆是指 $\text{CuSO}_4 \cdot 5\text{H}_2\text{O}$
C. “火树银花”火树就是指烟花，是金属单质的焰色试验，属于物理变化
D. 《本草纲目》：“水银乃至阴之毒物，因火煅丹砂($\text{HgS}$)而出”，其中发生了氧化还原反应
**勾选：C**
> 批注： 焰色反应本身是物理变化，但“火树银花”中烟花燃烧生成金属氧化物并伴随发光发热，属于化学变化，故C项错误。

2. 下列气体中，既有颜色又有毒性的是（  ）
A. $\text{N}_2$    B. $\text{SO}_2$    C. $\text{NO}_2$    D. $\text{NH}_3$
**勾选：C**
> 批注： $\text{NO}_2$ 为红棕色气体且有剧毒。$\text{SO}_2$ 和 $\text{NH}_3$ 无色有刺激性气味，$\text{N}_2$ 无色无毒。

3. 化学创造美好生活，下列说法错误的是（  ）
A. 超导陶瓷可应用于磁悬浮技术
B. 手机芯片和光导纤维的主要成分都是硅单质
C. 光化学烟雾和臭氧层空洞的形成均与 $\text{NO}_x$ 有关
D. $\text{SiC}$ 硬度很大，可用作砂轮的磨料，是一种新型无机非金属材料
**勾选：B**
> 批注： 光导纤维的主要成分是 $\text{SiO}_2$，不是硅单质，B项错误。

4. 用如图所示的装置分别进行如下导电性实验，小灯泡的亮度比反应前明显减弱的是（  ）
A. 向硫化钠溶液中通入氯气
B. 向硝酸银溶液中通入少量氯化氢
C. 向 $\text{HI}$ 饱和溶液中通入 $\text{O}_2$
D. 向氢氧化钠溶液中通入少量氯气
**勾选：C**
> 批注： $\text{C}$ 中发生反应 $4\text{HI} + \text{O}_2 = 2\text{I}_2 + 2\text{H}_2\text{O}$，生成弱电解质 $\text{H}_2\text{O}$ 和难溶单质 $\text{I}_2$，溶液中离子浓度明显减小，导电性明显减弱。

5. 下列实验操作或处理方法错误的是（  ）
A. 用稀硝酸清洗做过银镜反应的试管
B. 使用 $\text{pH}$ 试纸测定浓硫酸的 $\text{pH}$
C. 未使用完的金属钠可以放回原试剂瓶
D. 过滤时，滤纸边缘低于漏斗边缘
**勾选：B**
> 批注： 浓硫酸具有脱水性，会使 $\text{pH}$ 试纸碳化变黑，不能用来测 $\text{pH}$，B项错误。

6. 下列实验装置或操作能够达到实验目的的是（  ）
A. 灼烧海带    B. 制备 $\text{NO}_2$    C. 制备 $\text{Fe(OH)}_3$ 胶体    D. 检验生成的 $\text{CO}_2$
**勾选：A**
> 批注： 灼烧海带应在坩埚中进行，图示仪器为坩埚，可达到实验目的，A正确。B项铜与浓硝酸反应生成 $\text{NO}_2$，但装置不密封且不能收集到纯净 $\text{NO}_2$；C项应将饱和 $\text{FeCl}_3$ 溶液滴入沸水中制备胶体；D项木炭与浓硫酸反应生成的 $\text{SO}_2$ 和 $\text{CO}_2$ 均能使澄清石灰水变浑浊，无法检验 $\text{CO}_2$。

7. 通过加热反应实现的以镁元素为核心的物质转化关系如图。下列说法错误的是（  ）
A. 物质 $a, b$ 均为电解质，且 $b$ 能电离
B. 物质 $b$ 与 $\text{CuO}$ 的反应中，$b$ 作还原剂
C. 利用 $\text{NaOH}$ 溶液和红色石蕊试纸可检验 $\text{NH}_3$
D. $\text{Mg(OH)Cl}$ 既含离子键又含极性共价键
**勾选：A**
> 批注： 物质 $a$ 为 $\text{MgO}$，$b$ 为 $\text{MgCl}_2$。$\text{MgCl}_2$ 是离子化合物，在水溶液或熔融状态下能电离出离子。A项中“$b$ 能电离”脱离反应实质，说法牵强，为错误选项。

8. 下列有关硅及其化合物的叙述错误的是（  ）
A. 水晶、玛瑙、电子芯片等主要成分都是 $\text{SiO}_2$
B. 水玻璃是制备硅胶和木材防火剂的原料
C. 碳化硅俗称金刚砂，可用作砂纸和砂轮的磨料
D. 水泥、玻璃、陶瓷是三大传统硅酸盐产品
**勾选：A**
> 批注： 电子芯片的主要成分是单质硅，不是 $\text{SiO}_2$，A项错误。

9. 下列反应的方程式错误的是（  ）
A. 热 $\text{NaOH}$ 溶液洗涤试管里的硫：$3\text{S} + 6\text{OH}^- = 2\text{S}^{2-} + \text{SO}_3^{2-} + 3\text{H}_2\text{O}$
B. 向 $\text{Fe(NO}_3\text{)}_2$ 溶液中加入盐酸：$3\text{Fe}^{2+} + 4\text{H}^+ + \text{NO}_3^- = 3\text{Fe}^{3+} + \text{NO}\uparrow + 2\text{H}_2\text{O}$
C. 氢氧化亚铁溶于过量稀硝酸中：$\text{Fe(OH)}_2 + 2\text{H}^+ = \text{Fe}^{2+} + 2\text{H}_2\text{O}$
D. 二氧化硫和氯气按 1:1 通入水中：$\text{SO}_2 + \text{Cl}_2 + 2\text{H}_2\text{O} = 4\text{H}^+ + \text{SO}_4^{2-} + 2\text{Cl}^-$
**勾选：C**
> 批注： 稀硝酸具有强氧化性，会将 $\text{Fe}^{2+}$ 氧化为 $\text{Fe}^{3+}$。正确的离子方程式为 $3\text{Fe(OH)}_2 + 10\text{H}^+ + \text{NO}_3^- = 3\text{Fe}^{3+} + \text{NO}\uparrow + 8\text{H}_2\text{O}$，C错误。

10. 下列说法正确的是（  ）
A. $\text{NO}_2$ 与 $\text{NaOH}$ 反应生成 $\text{NaNO}_3, \text{NaNO}_2$，所以 $\text{NO}_2$ 是酸性氧化物
B. $\text{Na}_2\text{O}_2$ 与盐酸反应生成盐、水和氧气，所以 $\text{Na}_2\text{O}_2$ 是碱性氧化物
C. $\text{FeO}, \text{Fe}_2\text{O}_3$ 与硫酸反应只生成对应的盐和水，所以都是碱性氧化物
D. $\text{NaHSO}_4$ 能电离出氢离子溶液显酸性，所以 $\text{NaHSO}_4$ 是酸
**勾选：C**
> 批注： 酸性氧化物与碱反应只生成一种盐和水，A错；碱性氧化物与酸反应只生成盐和水，不生成 $\text{O}_2$，B错；$\text{NaHSO}_4$ 是酸式盐，不是酸，D错。C正确。

11. 物质的性质决定用途，下列两者对应关系不正确的是（  ）
A. 铝具有还原性，可用于制作门窗框架
B. 氧化钙易吸水，可用作干燥剂
C. $\text{SiO}_2$ 具有导光性，可用于制作光导纤维
D. 过氧化钠能与二氧化碳反应生成氧气，可作潜水艇中的供氧剂
**勾选：A**
> 批注： 铝可用于制作门窗框架是利用其质轻、硬度适中及表面有致密氧化膜抗腐蚀的性质，与还原性无关，A不正确。

12. 下列各组离子能大量共存的是（  ）
A. 使酚酞指示剂变红的溶液：$\text{NO}_3^-、\text{Cl}^-、\text{CO}_3^{2-}、\text{Na}^+$
B. 室温下，$\text{pH}=1$ 的溶液：$\text{K}^+、\text{NH}_4^+、\text{Cl}^-、\text{S}^{2-}$
C. 饱和 $\text{SO}_2$ 水溶液：$\text{Ba}^{2+}、\text{Na}^+、\text{Cl}^-、\text{NO}_3^-$
D. 含有 $\text{Fe}^{2+}$ 的溶液中：$\text{K}^+、\text{Na}^+、[\text{Fe(CN)}_6]^{3-}、\text{Cl}^-$
**勾选：A**
> 批注： 使酚酞变红的溶液呈碱性，四种离子在碱性环境中均能大量共存，A正确。B项中 $\text{S}^{2-}$ 在酸性条件下不能大量存在；C项中 $\text{NO}_3^-$ 在酸性条件下具有强氧化性，能将 $\text{SO}_2$ 氧化为 $\text{SO}_4^{2-}$，进而生成 $\text{BaSO}_4$ 沉淀；D项中 $\text{Fe}^{2+}$ 与 $[\text{Fe(CN)}_6]^{3-}$ 会生成蓝色的铁氰化亚铁沉淀。

13. 下列有关离子方程式的书写正确的是（  ）
A. $\text{H}_2\text{S}$ 通入 $\text{CuSO}_4$ 溶液中：$\text{Cu}^{2+} + \text{S}^{2-} = \text{CuS}\downarrow$
B. 向 $\text{Fe(NO}_3\text{)}_2$ 稀溶液中加入盐酸：$3\text{Fe}^{2+} + 4\text{H}^+ + \text{NO}_3^- = 3\text{Fe}^{3+} + \text{NO}\uparrow + 2\text{H}_2\text{O}$
C. $\text{SiO}_2$ 溶于 $\text{NaOH}$ 溶液：$\text{SiO}_2 + 2\text{Na}^+ + 2\text{OH}^- = \text{Na}_2\text{SiO}_3 + \text{H}_2\text{O}$
D. 向 $\text{BaCl}_2$ 溶液中通入 $\text{SO}_2$：$\text{Ba}^{2+} + \text{H}_2\text{O} + \text{SO}_2 = \text{BaSO}_3\downarrow + 2\text{H}^+$
**勾选：B**
> 批注： $\text{H}_2\text{S}$ 是弱酸不能拆成 $\text{S}^{2-}$，A错；$\text{Na}_2\text{SiO}_3$ 是可溶性盐应拆开，C错；$\text{SO}_2$ 不能与 $\text{BaCl}_2$ 溶液反应，D错。B正确。

14. 下列反应方程式表达正确的是（  ）
A. 漂白液漂白的原理：$\text{ClO}^- + \text{CO}_2 + \text{H}_2\text{O} = \text{HClO} + \text{CO}_3^{2-}$
B. 呼吸面具供氧的原理：$\text{Na}_2\text{O}_2 + \text{CO}_2 = 2\text{Na}_2\text{CO}_3 + \text{O}_2$
C. 向含有1 mol $\text{NH}_4\text{Al(SO}_4\text{)}_2$ 的溶液中加入2 mol $\text{Ba(OH)}_2$：$\text{Al}^{3+} + 2\text{SO}_4^{2-} + 2\text{Ba}^{2+} + 4\text{OH}^- = \text{AlO}_2^- + 2\text{BaSO}_4\downarrow + 2\text{H}_2\text{O}$
D. $\text{SO}_2$ 通入酸性 $\text{KMnO}_4$ 溶液中：$5\text{SO}_2 + 2\text{H}_2\text{O} + 2\text{MnO}_4^- = 5\text{SO}_4^{2-} + 4\text{H}^+ + 2\text{Mn}^{2+}$
**勾选：D**
> 批注： 酸性：$\text{H}_2\text{CO}_3 > \text{HClO} > \text{HCO}_3^-$，漂白液吸收 $\text{CO}_2$ 应生成 $\text{HCO}_3^-$，A错；呼吸面具方程式应为 $2\text{Na}_2\text{O}_2 + 2\text{CO}_2 = 2\text{Na}_2\text{CO}_3 + \text{O}_2$，B错；C中 $\text{NH}_4^+$ 也会与 $\text{OH}^-$ 反应，且 $\text{Al}^{3+}$ 会生成 $\text{Al(OH)}_3$ 沉淀而非 $\text{AlO}_2^-$（$\text{OH}^-$ 不足），C错。D正确。

## 综合填空题

15. 从废弃的声光器件（$\text{TeO}_2$，含 $\text{Al、Cu、SiO}_2$ 杂质）中提取粗碲的工艺流程如图。下列说法错误的是（  ）
A. 滤渣的主要成分为 $\text{Cu}$
B. 滤液1和滤液2混合可能产生白色沉淀
C. “氧化沉碲”中离子方程式为 $2\text{Na}^+ + \text{TeO}_3^{2-} + \text{ClO}^- = \text{Na}_2\text{TeO}_4\downarrow + \text{Cl}^-$
D. “溶解还原”中氧化剂和还原剂的物质的量之比为3:1
**勾选：C**
> 批注： “氧化沉碲”是碱性环境下的反应，产物应为 $\text{Na}_2\text{TeO}_4$，但 $\text{TeO}_2$ 与 $\text{SO}_2$ 类似为酸性氧化物，$\text{TeO}_3^{2-}$ 为弱酸根离子，氧化反应应生成 $\text{TeO}_4^{2-}$，方程式电荷不守恒，C项错误。

16. 回答下列问题。
(1) 在太阳能的作用下，缺铁氧化物[如 $\text{Fe}_3\text{O}_4$]能分解 $\text{CO}_2$，其过程如图所示。过程①的化学方程式是：$6\text{Fe}_3\text{O}_4 + \text{CO}_2 = 2\text{Fe}_4\text{O}_5 + \text{C}$（或符合图示计量比的方程式均可）。在过程②中每产生1mol $\text{O}_2$，转移电子 **4** mol。
(2) 锰的重要用途是制造锰钢。一种以高铁锰矿（含 $\text{MnO}_2, \text{Fe}_2\text{O}_3$ 及少量 $\text{FeO, CaO, K}_2\text{O, Na}_2\text{O}$）为原料生产金属锰的工艺流程如图。“焙烧还原”时，高铁锰矿中 $\text{MnO}_2$ 被还原为 $\text{MnO}$ 反应的化学方程式为：$\text{MnO}_2 + \text{C} = \text{MnO} + \text{CO}\uparrow$（或 $2\text{MnO}_2 + \text{C} = 2\text{MnO} + \text{CO}_2\uparrow$）。被还原的物质还有 **$\text{Fe}_2\text{O}_3、\text{FeO}$**。
(3) 氮的循环对生命活动有重要意义。在不同催化剂下，$\text{H}_2$ 能够还原氮氧化物($\text{NO}_2$)。硝酸厂的烟气中含有大量的氮氧化物($\text{NO}_x$)，将烟气与 $\text{H}_2$ 的混合气体通入 $\text{Ce}_2(\text{SO}_4)_3$ 与 $\text{Ce}_2(\text{SO}_4)_4$ 的混合溶液中实现无害化处理。
① 该处理过程中，起催化作用的离子是 **$\text{Ce}^{3+}$**（或 $\text{Ce}^{4+}$）。
② $x = 2$ 时，$\text{Ce}^{3+}$ 参与的离子方程式为：$2\text{Ce}^{3+} + 2\text{H}^+ + \text{NO}_2 = 2\text{Ce}^{4+} + \text{NO} + \text{H}_2\text{O}$。
③ 若该过程中，每转移3mol电子消耗1mol氮氧化物($\text{NO}_x$)，则 $x$ 为 **2**。

(1) 合成氨工业化，工业上合成氨的化学方程式为：$\text{N}_2 + 3\text{H}_2 \rightleftharpoons 2\text{NH}_3$。
(2) ① 叠氮化钠（$\text{NaN}_3$）用于汽车安全气囊的产气药，$\text{NaN}_3$ 在撞击时能分解生成两种单质。理论上65g $\text{NaN}_3$ 完全分解，释放出标准状况下的气体体积 **33.6** L。
② 氮化铝（$\text{AlN}$）具有优良性质，工业上将氧化铝、氮气和碳在一定条件下反应制得 $\text{AlN}$ 和 $\text{CO}$，反应方程式为：$\text{Al}_2\text{O}_3 + \text{N}_2 + 3\text{C} = 2\text{AlN} + 3\text{CO}$。
(3) 利用元素的化合价推测物质的性质。如图是硫元素的“价-类”二维图：
① 从硫元素化合价变化的角度分析，图中既有氧化性又有还原性的化合物有 **$\text{SO}_2、\text{Na}_2\text{SO}_3、\text{H}_2\text{SO}_3$**（或Y、Z等，填化学式）。
② Z的浓溶液与铝单质在加热条件下可以发生化学反应生成Y，该反应的化学方程式为：$2\text{Al} + 6\text{H}_2\text{SO}_4(\text{浓}) = \text{Al}_2(\text{SO}_4)_3 + 3\text{SO}_2\uparrow + 6\text{H}_2\text{O}$。可用 **向上排空气** 法收集Y。

18. 某实验小组利用以下装置制取氨气并探究氨气的性质：
(1) 装置A中发生反应的化学方程式为：$2\text{NH}_4\text{Cl} + \text{Ca(OH)}_2 = \text{CaCl}_2 + 2\text{NH}_3\uparrow + 2\text{H}_2\text{O}$。
(2) 装置B中的干燥剂是 **碱石灰**。

(5) 为防止过量氨气外逸，需在上述装置末端增加尾气吸收装置，应选用的装置是 **E**（填“E”或“F”）。

19. $\text{N}_2\text{O、NO}$ 和 $\text{NO}_2$ 等氮氧化物是空气污染物。
(1) $\text{N}_2\text{O}$ 的处理。$\text{N}_2\text{O}$ 是硝酸生产中氨催化氧化的副产物，用特种催化剂能使 $\text{N}_2\text{O}$ 分解。$\text{NH}_3$ 与 $\text{O}_2$ 在加热和催化剂作用下生成 $\text{N}_2\text{O}$ 的化学方程式为：$2\text{NH}_3 + 2\text{O}_2 = \text{N}_2\text{O} + 3\text{H}_2\text{O}$。
(2) $\text{NO}$ 和 $\text{NO}_2$ 的处理。已除去 $\text{N}_2\text{O}$ 的硝酸尾气可用 $\text{NaOH}$ 溶液吸收，主要反应为：
$\text{NO} + \text{NO}_2 + 2\text{OH}^- = 2\text{NO}_2^- + \text{H}_2\text{O}$
$2\text{NO}_2 + 2\text{OH}^- = \text{NO}_2^- + \text{NO}_3^- + \text{H}_2\text{O}$
① 下列措施能提高尾气中 $\text{NO}$ 和 $\text{NO}_2$ 去除率的有 **BC**。
② 吸收后的溶液经浓缩、结晶、过滤，得到 $\text{NaNO}_2$ 晶体，该晶体中的主要杂质是 **$\text{NaNO}_3$**；吸收后排放的尾气中含量较高的氮氧化物是 **$\text{NO}$**。
(3) $\text{NO}$ 的氧化吸收。用 $\text{NaClO}$ 溶液吸收硝酸尾气，可提高尾气中 $\text{NO}$ 的去除率。其他条件相同，$\text{NO}$ 转化为 $\text{NO}_3^-$ 的转化率随 $\text{NaClO}$ 溶液初始 $\text{pH}$ 的变化如图所示。
① 在酸性 $\text{NaClO}$ 溶液中，$\text{HClO}$ 氧化 $\text{NO}$ 生成 $\text{Cl}^-$ 和 $\text{NO}_3^-$，其离子方程式为：$3\text{HClO} + 2\text{NO} + \text{H}_2\text{O} = 3\text{Cl}^- + 2\text{NO}_3^- + 5\text{H}^+$。
② $\text{NaClO}$ 溶液的初始 $\text{pH}$ 越小，$\text{NO}$ 转化率越高。其原因是 **$\text{pH}$ 越小，溶液中 $\text{HClO}$ 的浓度越大，$\text{HClO}$ 的氧化性越强，使 $\text{NO}$ 氧化得更彻底**。
