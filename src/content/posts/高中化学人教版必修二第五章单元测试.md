# 高中化学人教版必修二第五章单元测试

## 一、单选题
1. 中国古代诗词和书籍中蕴含着化学知识。下列说法错误的是（  ）
A. “白玉金边素瓷胎，雕龙描凤巧安排”，陶瓷材料是人类应用最早的硅酸盐材料
B. 我国古代典籍中有“石胆……浅碧色，烧之变白色者真”的记载，其中石胆是指 CuSO₄·5H₂O
C. “火树银花”火树就是指烟花，是金属单质的焰色试验，属于物理变化
D. 《本草纲目》：“水银乃至阴之毒物，因火煅丹砂(HgS)而出”，其中发生了氧化还原反应
**答案：C**
（解析：焰色反应是物理变化，但“火树银花”中发生的燃烧反应生成金属氧化物并伴随发光发热，属于化学变化，故C项错误。）

2. 下列气体中，既有颜色又有毒性的是（  ）
A. N₂  B. SO₂  C. NO₂  D. NH₃
**答案：C**
（解析：NO₂为红棕色气体且有毒，SO₂和NH₃无色有刺激性气味，N₂无色无毒。）

3. 化学创造美好生活，下列说法错误的是（  ）
A. 超导陶瓷可应用于磁悬浮技术
B. 手机芯片和光导纤维的主要成分都是硅单质
C. 光化学烟雾和臭氧层空洞的形成均与NOₓ有关
D. SiC硬度很大，可用作砂轮的磨料，是一种新型无机非金属材料
**答案：B**
（解析：光导纤维的主要成分是SiO₂，不是硅单质，B项错误。）

4. 用如图所示的装置分别进行如下导电性实验，小灯泡的亮度比反应前明显减弱的是（  ）
A. 向硫化钠溶液中通入氯气
B. 向硝酸银溶液中通入少量氯化氢
C. 向HI饱和溶液中通入O₂
D. 向氢氧化钠溶液中通入少量氯气
**答案：C**
（解析：C中发生反应4HI+O₂=2I₂+2H₂O，生成弱电解质H₂O和难溶单质I₂，溶液中离子浓度明显减小，导电性明显减弱。）

5. 下列实验操作或处理方法错误的是（  ）
A. 用稀硝酸清洗做过银镜反应的试管
B. 使用pH试纸测定浓硫酸的pH
C. 未使用完的金属钠可以放回原试剂瓶
D. 过滤时，滤纸边缘低于漏斗边缘
**答案：B**
（解析：浓硫酸具有脱水性，会使pH试纸碳化变黑，不能用来测pH，B项错误。）

6. 下列实验装置或操作能够达到实验目的的是（  ）
A. 灼烧海带  B. 制备NO₂  C. 制备Fe(OH)₃胶体  D. 检验生成的CO₂
**答案：A**
（解析：A项灼烧海带应在坩埚中进行，图示仪器为坩埚，可达到实验目的；B项铜与浓硝酸反应生成NO₂，但是装置不密封且不能收集到纯净NO₂；C项应将饱和FeCl₃溶液滴入沸水中制备胶体；D项木炭与浓硫酸反应生成的SO₂和CO₂均能使澄清石灰水变浑浊，无法检验CO₂。）

7. 通过加热反应实现的以镁元素为核心的物质转化关系如图。下列说法错误的是（  ）
（图示：MgO 与 NH₄Cl 加热生成 Mg(OH)Cl 和 NH₃；Mg(OH)Cl 加热生成 MgO 和 HCl）
A. 物质a、b均为电解质，且b能电离
B. 物质b与CuO的反应中，b作还原剂
C. 利用NaOH溶液和红色石蕊试纸可检验NH₃
D. Mg(OH)Cl既含离子键又含极性共价键
**答案：A**
（解析：物质a为MgO，b为MgCl₂。MgCl₂是离子化合物，在水溶液或熔融状态下能电离出离子，但MgO是电解质但固态时不导电，且其难溶于水，加热反应时的物质转化并未体现出b“能电离”的必要条件，此说法牵强。实际上，B中描述2MgCl₂ + O₂ = 2MgO + 2Cl₂中MgCl₂作还原剂，过程正确；C、D表述完全正确。综合来看A项描述脱离反应实质，为错误选项。）

8. 下列有关硅及其化合物的叙述错误的是（  ）
A. 水晶、玛瑙、电子芯片等主要成分都是SiO₂
B. 水玻璃是制备硅胶和木材防火剂的原料
C. 碳化硅俗称金刚砂，可用作砂纸和砂轮的磨料
D. 水泥、玻璃、陶瓷是三大传统硅酸盐产品
**答案：A**
（解析：电子芯片的主要成分是单质硅，A项错误。）

9. 下列反应的方程式错误的是（  ）
A. 热NaOH溶液洗涤试管里的硫：3S + 6OH⁻ = 2S²⁻ + SO₃²⁻ + 3H₂O
B. 向Fe(NO₃)₂溶液中加入盐酸：3Fe²⁺ + 4H⁺ + NO₃⁻ = 3Fe³⁺ + NO↑ + 2H₂O
C. 氢氧化亚铁溶于过量稀硝酸中：Fe(OH)₂ + 2H⁺ = Fe²⁺ + 2H₂O
D. 二氧化硫和氯气按1:1通入水中：SO₂ + Cl₂ + 2H₂O = 4H⁺ + SO₄²⁻ + 2Cl⁻
**答案：C**
（解析：稀硝酸具有强氧化性，会将Fe²⁺氧化为Fe³⁺。正确的离子方程式为3Fe(OH)₂ + 10H⁺ + NO₃⁻ = 3Fe³⁺ + NO↑ + 8H₂O。）

10. 下列说法正确的是（  ）
A. NO₂与NaOH反应生成NaNO₃、NaNO₂，所以NO₂是酸性氧化物
B. Na₂O₂与盐酸反应生成盐、水和氧气，所以Na₂O₂是碱性氧化物
C. FeO、Fe₂O₃与硫酸反应只生成对应的盐和水，所以都是碱性氧化物
D. NaHSO₄能电离出氢离子溶液显酸性，所以NaHSO₄是酸
**答案：C**
（解析：酸性氧化物与碱反应只生成一种盐和水，A错；碱性氧化物与酸反应只生成盐和水，不生成O₂，B错；NaHSO₄是酸式盐，不是酸，D错。）

11. 物质的性质决定用途，下列两者对应关系不正确的是（  ）
A. 铝具有还原性，可用于制作门窗框架
B. 氧化钙易吸水，可用作干燥剂
C. SiO₂具有导光性，可用于制作光导纤维
D. 过氧化钠能与二氧化碳反应生成氧气，可作潜水艇中的供氧剂
**答案：A**
（解析：铝可用于制作门窗框架是利用其质轻、硬度适中及表面有致密氧化膜抗腐蚀的性质，与还原性无关。）

12. 下列各组离子能大量共存的是（  ）
A. 使酚酞指示剂变红的溶液：NO₃⁻、Cl⁻、CO₃²⁻、Na⁺
B. 室温下，pH=1的溶液：K⁺、NH₄⁺、Cl⁻、S²⁻
C. 饱和SO₂水溶液：Ba²⁺、Na⁺、Cl⁻、NO₃⁻
D. 含有Fe²⁺的溶液中：K⁺、Na⁺、[Fe(CN)₆]³⁻、Cl⁻
**答案：A**
（解析：使酚酞变红的溶液呈碱性，四种离子在碱性环境中均能大量共存；B项中S²⁻在酸性条件下不能大量存在；C项中NO₃⁻在酸性条件下具有强氧化性，能将SO₂氧化为SO₄²⁻，进而生成BaSO₄沉淀；D项中Fe²⁺与[Fe(CN)₆]³⁻会生成蓝色的铁氰化亚铁沉淀。）

13. 下列有关离子方程式的书写正确的是（  ）
A. H₂S通入CuSO₄溶液中：Cu²⁺ + S²⁻ = CuS↓
B. 向Fe(NO₃)₂稀溶液中加入盐酸：3Fe²⁺ + 4H⁺ + NO₃⁻ = 3Fe³⁺ + NO↑ + 2H₂O
C. SiO₂溶于NaOH溶液：SiO₂ + 2Na⁺ + 2OH⁻ = Na₂SiO₃ + H₂O
D. 向BaCl₂溶液中通入SO₂：Ba²⁺ + H₂O + SO₂ = BaSO₃↓ + 2H⁺
**答案：B**
（解析：H₂S是弱酸不能拆成S²⁻，A错；Na₂SiO₃是可溶性盐应拆开，C错；SO₂不能与BaCl₂溶液反应，D错。）

14. 下列反应方程式表达正确的是（  ）
A. 漂白液漂白的原理：ClO⁻ + CO₂ + H₂O = HClO + CO₃²⁻
B. 呼吸面具供氧的原理：Na₂O₂ + CO₂ = 2Na₂CO₃ + O₂
C. 向含有1 mol NH₄Al(SO₄)₂的溶液中加入2 mol Ba(OH)₂：Al³⁺ + 2SO₄²⁻ + 2Ba²⁺ + 4OH⁻ = AlO₂⁻ + 2BaSO₄↓ + 2H₂O
D. SO₂通入酸性KMnO₄溶液中：5SO₂ + 2H₂O + 2MnO₄⁻ = 5SO₄²⁻ + 4H⁺ + 2Mn²⁺
**答案：D**
（解析：酸性：H₂CO₃ > HClO > HCO₃⁻，漂白液吸收CO₂应生成HCO₃⁻，A错；呼吸面具方程式应为2Na₂O₂ + 2CO₂ = 2Na₂CO₃ + O₂，B错；C中NH₄⁺也会与OH⁻反应，且Al³⁺会生成Al(OH)₃沉淀而非AlO₂⁻（OH⁻不足），C错。）

19. N₂O、NO和NO₂等氮氧化物是空气污染物，含有氮氧化物的尾气需处理后才能排放。
(1) N₂O的处理。N₂O是硝酸生产中氨催化氧化的副产物，用特种催化剂能使N₂O分解。NH₃与O₂在加热和催化剂作用下生成N₂O的化学方程式为：**2NH₃ + 2O₂ = N₂O + 3H₂O**。
(2) NO和NO₂的处理。已除去N₂O的硝酸尾气可用NaOH溶液吸收，主要反应为：NO + NO₂ + 2OH⁻ = 2NO₂⁻ + H₂O。
2NO₂ + 2OH⁻ = NO₂⁻ + NO₃⁻ + H₂O
①下列措施能提高尾气中NO和NO₂去除率的有 **B、C**（填字母）。
A. 加快通入尾气的速率（减小接触时间，去除率降低）
B. 采用气、液逆流的方式吸收尾气（增加接触面积，去除率升高）
C. 吸收尾气过程中定期补加适量NaOH溶液（保持碱性，促进反应正向进行，去除率升高）
②吸收后的溶液经浓缩、结晶、过滤，得到NaNO₂晶体，该晶体中的主要杂质是 **NaNO₃**（填化学式）；吸收后排放的尾气中含量较高的氮氧化物是 **NO**（填化学式）。
(3) NO的氧化吸收。用NaClO溶液吸收硝酸尾气，可提高尾气中NO的去除率。其他条件相同，NO转化为NO₃⁻的转化率随NaClO溶液初始pH（用稀盐酸调节）的变化如图所示。
①在酸性NaClO溶液中，HClO氧化NO生成Cl⁻和NO₃⁻，其离子方程式为：**3HClO + 2NO + H₂O = 3Cl⁻ + 2NO₃⁻ + 5H⁺**。
②NaClO溶液的初始pH越小，NO转化率越高。其原因是 **pH越小，溶液中HClO的浓度越大，HClO的氧化性越强，使NO氧化得更完全**。
