# 高一下期数学期末复习题二

## 一、单选题
1. 在复平面内，复数对应的点的坐标是(1,2)，则其共轭复数 \(\overline{z} = (\quad)\)
   A. \(1+2i\) \quad B. \(1-2i\) \quad C. \(-1+2i\) \quad D. \(-1-2i\)
   **答案：B**

2. 已知 \(\triangle ABC\) 是边长为4的等边三角形，则 \(\overrightarrow{AB} \cdot \overrightarrow{AC} = (\quad)\)
   A. \(4\) \quad B. \(-4\) \quad C. \(8\) \quad D. \(-8\)
   **答案：C**

3. 已知 \(\alpha, \beta, \gamma\) 为空间中不重合的平面，\(m, n\) 为空间中不重合的直线，下列命题正确的是 \((\quad)\)
   A. 若 \(m // n, n \subset \alpha\), 则 \(m // \alpha\) \quad B. 若 \(m // \alpha, n \perp \alpha\), 则 \(m \perp n\)
   C. 若 \(\alpha \perp \gamma, \beta \perp \gamma\), 则 \(\alpha // \beta\) \quad D. 若 \(\alpha // \beta, m \subset \alpha, n \subset \beta\), 则 \(m // n\)
   **答案：B**

4. 在 \(\triangle ABC\) 中，角 \(A, B, C\) 所对的边分别为 \(a, b, c\)，若 \(a=3, C=45^\circ, \sin B = \frac{\sqrt{5}}{5}\)，则 \(c = (\quad)\)
   A. \(5\) \quad B. \(\sqrt{5}\) \quad C. \(\sqrt{3}\) \quad D. \(4\)
   **答案：B**

5. 在等腰梯形 \(ABCD\) 中，\(AB // DC, AB = 2BC = 2CD = 2\)，\(P\) 是底边 \(AB\) 上的动点，则 \(\overrightarrow{PD} \cdot \overrightarrow{PC}\) 的最小值为 \((\quad)\)
   A. \(2\sqrt{2}\) \quad B. \(2\) \quad C. \(\frac{3}{2}\) \quad D. \(\frac{1}{2}\)
   **答案：D**

6. 位于灯塔 \(A\) 处正西方相距30海里的 \(B\) 处有一艘甲船，需要海上加油，位于灯塔 \(A\) 处北偏东 \(45^\circ\) 方向有一与灯塔 \(A\) 相距 \(10\sqrt{2}\) 海里的 \(C\) 处有一艘乙船，则乙船前往支援 \(B\) 处甲船需要航行的最短距离是 \((\quad)\)
   A. \(10\sqrt{5}\) 海里 \quad B. \(10\sqrt{17}\) 海里
   C. \(8\sqrt{17}\) 海里 \quad D. \(30\) 海里
   **答案：B**

7. 已知三棱锥 \(S-ABC\) 底面边长均为 \(3\)，侧棱 \(SA=2\)，且 \(SA \perp \text{平面 } ABC\)，则该三棱锥外接球的半径长为 \((\quad)\)
   A. \(2\) \quad B. \(\frac{5}{2}\) \quad C. \(3\) \quad D. \(\sqrt{3}\)
   **答案：A**

8. 十七世纪法国数学家、被誉为业余数学家之王的皮埃尔·德·费马提出一个著名的几何问题：已知一个三角形，求作一点，使其与这个三角形的三个顶点的距离之和最小。在费马提出的这个问题中所求的点被称为费马点，其答案如下：当三角形的三个角均小于 \(120^\circ\) 时，所求的点为三角形的正等角中心，即该点与三角形三个顶点的连线两两成 \(120^\circ\) 角；当三角形有一内角大于或等于 \(120^\circ\) 时，所求的点为三角形最大内角的顶点。已知 \(a, b, c\) 分别是 \(\triangle ABC\) 的内角 \(A, B, C\) 所对的边，且 \(a^2 - (b-c)^2 = 8, b\sin\frac{B+C}{2} = a\sin B\)，若 \(P\) 为 \(\triangle ABC\) 的费马点，则 \(\overrightarrow{PA} \cdot \overrightarrow{PB} + \overrightarrow{PB} \cdot \overrightarrow{PC} + \overrightarrow{PA} \cdot \overrightarrow{PC} = (\quad)\)
   A. \(-4\) \quad B. \(-3\) \quad C. \(-6\) \quad D. \(-\frac{3}{2}\)
   **答案：A**

## 二、多选题
9. 已知 \(i\) 是虚数单位，复数 \(z = \frac{2+i}{2-i}\)，则下列说法正确的是 \((\quad)\)
   A. 复数 \(z\) 的虚部为 \(4i\) \quad B. \(z = 3 - 4i\)
   C. \(|z| = 5\) \quad D. \(z\) 在复平面内对应的点在第一象限
   **答案：D**

10. 已知点 \(P\) 是 \(\triangle ABC\) 所在平面内一点，且 \(\overrightarrow{AP} = 2m\overrightarrow{AB} + n\overrightarrow{AC}, m, n \in \mathbb{R}\)，则下列说法正确的是 \((\quad)\)
    A. 若 \(m=n=\frac{1}{2}\)，则点 \(P\) 是边 \(BC\) 的中点
    B. 若点 \(P\) 是边 \(BC\) 上靠近 \(B\) 点的三等分点，则 \(m=n=\frac{1}{3}\)
    C. 若 \(2m+n=\frac{1}{2}\)，则 \(S_{\triangle PBC} = 2S_{\triangle ABC}\)
    D. 若点 \(P\) 在 \(BC\) 边的中线上，且 \(2m+n=\frac{2}{3}\)，则点 \(P\) 是 \(\triangle ABC\) 的重心
    **答案：A**

11. 如图，在正三棱台 \(ABC-A_1B_1C_1\) 中，\(AB = 2A_1B_1 = 2\)，\(P, D\) 分别是线段 \(B_1C_1, BC\) 上的点，\(O_1, O\) 分别是上、下底面的中心，\(M\) 是底面 \(ABC\) 内一点，下列结论正确的是 \((\quad)\)

    **答案：D**

## 四、解答题
15. 已知 \(\vec{a} = (\sqrt{2}, 1), |\vec{b}| = 2, \langle \vec{a}, \vec{b} \rangle = 30^\circ\)，记 \(\vec{a}\) 在 \(\vec{b}\) 方向上的投影向量为 \(\vec{c}\)。
    (1) 求 \(|\vec{a} - 2\vec{c}|\) 的值；
    (2) 若向量 \((\vec{a} - \frac{2}{3}\vec{c})\) 与 \((\lambda\vec{a} - 4\vec{c})\) 的夹角为钝角，求实数 \(\lambda\) 的取值范围。
    **答案：**
    (1) \(\sqrt{3}\)
    (2) \(\lambda < 2\)

16. 如图，在直四棱柱 \(ABCD-A_1B_1C_1D_1\) 中，底面 \(ABCD\) 为平行四边形，\(M\) 为 \(AA_1\) 中点。
    (1) 求证：\(A_1C // \text{平面 } BMD\)；
    (2) 若 \(BD \perp A_1C\)，证明：底面 \(ABCD\) 为菱形。
    **证明：**
    (1) 连接 \(AC\) 交 \(BD\) 于 \(O\)，连接 \(MO\)。在 \(\triangle ACA_1\) 中，\(M\) 为 \(AA_1\) 中点，\(O\) 为 \(AC\) 中点，所以 \(MO\) 为 \(\triangle ACA_1\) 的中位线，故 \(MO // A_1C\)。又因为 \(MO \subset \text{平面 } BMD\)，\(A_1C \not\subset \text{平面 } BMD\)，所以 \(A_1C // \text{平面 } BMD\)。
    (2) 因为 \(ABCD-A_1B_1C_1D_1\) 是直四棱柱，所以 \(AA_1 \perp \text{平面 } ABCD\)，故 \(AA_1 \perp BD\)。又因为 \(BD \perp A_1C\)，\(AA_1 \cap A_1C = A_1\)，所以 \(BD \perp \text{平面 } A_1AC\)。因为 \(AC \subset \text{平面 } A_1AC\)，所以 \(BD \perp AC\)。因为底面 \(ABCD\) 为平行四边形，且其对角线 \(AC \perp BD\)，所以底面 \(ABCD\) 为菱形。

17. 在 \(\triangle ABC\) 中，\(BC, AC\) 边上的两条中线 \(AM, BN\) 相交于点，若 \(AB : AM : AC = 6 : 7 : 10\)。
    (1) 用 \(\overrightarrow{AB}, \overrightarrow{AC}\) 表示 \(\overrightarrow{AM}, \overrightarrow{BN}\)；
    (2) 求 \(\angle BAC\)；
    (3) 若 \(\overrightarrow{AM} \cdot \overrightarrow{BN} = -2\)，求四边形 \(PMCN\) 的面积。
    **答案：**
    (1) \(\overrightarrow{AM} = \frac{1}{2}(\overrightarrow{AB} + \overrightarrow{AC})\)；\(\overrightarrow{BN} = \frac{1}{2}\overrightarrow{AC} - \overrightarrow{AB}\)
    (2) \(\frac{\pi}{3}\)
    (3) \(20\sqrt{3}\)

18. 已知 \(\triangle ABC\) 的三个内角 \(A, B, C\) 的对边分别为 \(a, b, c\)，且 \(\sqrt{3}a\cos C - \sqrt{3}b = c\sin A\)。
    (1) 求角 \(A\)；
    (2) 若 \(\triangle ABC\) 的面积为 \(\frac{\sqrt{3}}{2}\)，且 \(\sin B = 2\sin C\)。
       ① 求 \(\triangle ABC\) 的周长；
       ② 求 \(\sin(B-A)\)。
    **答案：**
    (1) \(\frac{2\pi}{3}\)
    (2) ① \(3 + \sqrt{7}\)；② \(-\frac{3\sqrt{21}}{14}\)

19. 如图，在四棱锥 \(P-ABCD\) 中，\(\triangle PCD\) 为等边三角形，平面 \(PAC \perp \text{平面 } PCD\)，\(PA \perp PD\)，\(AB = 2, AD = 4, PB = 2\sqrt{3}\)。
    (1) 求证：\(PA \perp \text{平面 } PCD\)；
    (2) 求直线 \(AD\) 与平面 \(PAC\) 所成角的正弦值；
    (3) 线段 \(PC\) 上是否存在一点 \(M\)，使得二面角 \(M-AB-C\) 的平面角的余弦值为 \(\frac{8\sqrt{3}}{15}\)，若存在，求出 \(\frac{PM}{MC}\) 的值；若不存在，请说明理由。
    **答案：**
    (1) 证明略（利用几何关系与线面垂直判定定理）。
    (2) \(\frac{\sqrt{6}}{4}\)
    (3) 存在，\(\frac{PM}{MC} = 1\)
